# Weekly News Digest

Автономная еженедельная новостная рассылка на русском языке. GitHub Actions запускает её по понедельникам в 08:00 по часовому поясу `Europe/Copenhagen`; дополнительные попытки до 10:00 защищают от пропущенного события планировщика. Повторные запуски не отправляют дубликат, поскольку успешный выпуск сохраняется в `reports/`.

Дайджест содержит:

1. три главные мировые новости;
2. две новости Дании и Копенгагена;
3. три главные экономические новости;
4. изменения миграционной политики Дании и правил permanent residence;
5. две новости астрофизики из научных и официальных источников.

Материалы за семь завершённых календарных дней собираются через Google News RSS с резервным источником GDELT. Скрипт фильтрует и дедуплицирует материалы, переводит заголовки и доступные описания на русский язык и всегда сохраняет ссылку на источник. Рассылка не зависит от отдельного AI API.

## Secrets

- `EMAIL_TO`
- `SMTP_USERNAME`
- `SMTP_PASSWORD`

## Ручной запуск

`Actions → Weekly news digest → Run workflow`. Опция `force_send` позволяет повторно отправить уже созданный выпуск.
