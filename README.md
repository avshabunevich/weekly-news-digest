# Weekly News Digest

Автономная еженедельная новостная рассылка на русском языке. Google Cloud
Scheduler запускает Cloud Run Job по понедельникам в 08:00 по часовому поясу
`Europe/Copenhagen`. Cloud Run повторяет временно неуспешные задачи, а Firestore
не допускает повторной рассылки одного еженедельного выпуска. GitHub Actions
оставлен только для ручного аварийного запуска.

Дайджест содержит:

1. три главные мировые новости и до двух дополнительных важных событий о безопасности и бедствиях;
2. две новости Дании и Копенгагена;
3. три главные экономические новости;
4. изменения миграционной политики Дании и правил permanent residence;
5. две новости астрофизики из научных и официальных источников.

Материалы за семь завершённых календарных дней собираются через Google News RSS с резервным источником GDELT. Скрипт фильтрует и дедуплицирует материалы, переводит заголовки и доступные описания на русский язык и всегда сохраняет ссылку на источник. Рассылка не зависит от отдельного AI API.

## Отбор главных событий

Раздел «Мир» собирает несколько поисковых выдач: общие международные новости,
политика, безопасность (включая теракты, попытки угона и авиационные происшествия),
стихийные бедствия. Дополнительный запрос к информагентствам помогает находить
основные сообщения среди многочисленных перепечаток и комментариев.
Поиск ограничен датами выпуска, а не последними семью днями на момент повтора.

Все найденные кандидаты ранжируются до сокращения списка. Близкие заголовки и
обновления об именованном урагане объединяются. Учитываются число разных
изданий, наличие известных новостных источников и признаки масштабного события.
Один издатель не получает дополнительный вес за повторные публикации.
Это эвристика значимости: разные издания могут перепечатывать одно агентство,
а автоматическая группировка не гарантирует распознавание всех дублей.

Если в основных трёх событиях нет новости о серьёзной угрозе безопасности или
бедствии, добавляется до одного материала каждого вида из известных источников.
Названия компаний и конкретных происшествий в алгоритме не закреплены.
Те же правила отбора действуют без доступа к AI; в журнал записываются выбранные
заголовки и количество кандидатов. Тесты: `python -m pytest -q`.

## Secrets

- `EMAIL_TO`
- `SMTP_USERNAME`
- `SMTP_PASSWORD`

## Ручной запуск

`Actions → Weekly news digest → Run workflow`. Опция `force_send` позволяет повторно отправить уже созданный выпуск.
